# TypeScript Tenant

`build_tenants/typescript/` is the planned project realization tenant for the
odd_sdlc.TS migration.

Current status: migration target.

This tenant records the intended source-side landing zone for a TypeScript
realization of `odd_world_model`. The current executable realization remains the
Python tenant until TypeScript requirements, design, code, and proof surfaces are
materialized under this root.

The installed governance/runtime payload for `odd_sdlc.TS` lives under
`.abiogenesis/odd_sdlc/typescript/` and is not project source truth.
