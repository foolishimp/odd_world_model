# Historical Filesystem Runner

This directory preserves the pre-GTL filesystem constructor as lineage and
comparison material. It is outside `code/src`, outside the current test glob,
not exported, not packaged as a binary, and not admissible as current product
or requirement proof.

Its local event, convergence, ledger, publication, and query files are
historical projections. They are not ABG runtime events or published WM truth.
Reusing any implementation detail requires a design reframe through the current
GraphFunction and admission contracts.
