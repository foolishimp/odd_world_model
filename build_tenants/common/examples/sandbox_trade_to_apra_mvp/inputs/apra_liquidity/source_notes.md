# APRA Liquidity Notes

This sandbox input stands in for a bounded APRA-liquidity regulatory slice.

The official APRA source set for this slice is recorded separately in:

- `source_authority.md`
- `authority_claims.json`
- `authority/apra_liquidity_landing_page.html`
- `authority/aps_210_liquidity_2025.html`
- `authority/apg_210_liquidity_2025.pdf`
- `authority/ars_210_0_liquidity_2023.html`
- `authority/apra_liquidity_faq.html`

The local semantic center is:

- regulatory reporting position
- counterparty classification
- agreement treatment basis
- liquidity bucket assignment

The current retained slice now includes a bounded extracted authority-claim
surface over the official APRA documents. It remains intentionally narrow and
is still not a full direct extracted APRA reporting ledger.
