# Python Design Reference

The files in this folder are retained design evidence for the old Python
tenant.

They are now stale reference material for the TypeScript rebuild. They may be
read to understand the earlier feature layering, semantic build line, module
groups, and proof lanes. They do not define the current target realization.

Current target design lives under:

- `build_tenants/typescript/design/`

Use these Python files only through the reference-derived mapping in:

- `build_tenants/typescript/design/adrs/ADR-003-reference-derived-design-carry-forward.md`

The Python-specific stack, commands, package names, pytest lanes, and generated
Python-first implementation choices are historical evidence.
