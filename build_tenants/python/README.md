# Python Tenant

`build_tenants/python/` is the stale reference implementation tenant.

The forward realization tenant is now:

- `build_tenants/typescript/`

Python remains available as historical implementation and comparison evidence.
It is not the current target realization authority.

The retained Python implementation previously carried these responsibilities:

- deterministic validation of the common JSON carrier
- file-first loading of published fragments and semantic objects
- bounded source adapters for real representation standards
- support for later projection generation from the same governed model
- sandbox builders for the first MVP proof lanes
- proof-lane builders that emit conventional and covariant outputs from the
  same semantic kernel

Current TypeScript design carries forward relevant structure through:

- `build_tenants/typescript/design/adrs/ADR-003-reference-derived-design-carry-forward.md`
