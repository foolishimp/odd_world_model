# Governed Context Memory Constraint Requirements

**Family**: REQ-ODD-WORLD-MODEL-CONTEXT-MEMORY-CONSTRAINT-*
**Status**: Active
**Category**: Constraint / Guarantee

### REQ-ODD-WORLD-MODEL-CONTEXT-MEMORY-CONSTRAINT-001 — No Basisless Governed Output

**Carries**:
- `INTENT.md` — `Constraints`
- `PRODUCT.md` — `Governed Context Memory`

An LLM output without a resolvable context-basis ref SHALL NOT be accepted as
governed proof, admitted semantic evidence, or published world-model truth.

### REQ-ODD-WORLD-MODEL-CONTEXT-MEMORY-CONSTRAINT-002 — Context Projection Is Not Truth

**Carries**:
- `WORLD_MODEL_METHOD.md` — `Single Truth Surface`, `Projection Law`
- `PRODUCT.md` — `Single Truth Surface`, `Context Projection`

A context projection, prompt body, cache, retrieval index, or model-native
memory SHALL remain downstream of published semantic truth. It SHALL retain its
basis ref and SHALL NOT become a rival semantic authority.

### REQ-ODD-WORLD-MODEL-CONTEXT-MEMORY-CONSTRAINT-003 — LLM Output Remains A Proposal

**Carries**:
- `PRODUCT.md` — `Semantic Construction And Admission Boundary`, `Governed Context Memory`
- `ODD_METHOD.md` — `Probabilistic Compute`

An LLM output SHALL remain an `F_P` proposal. It SHALL NOT directly write
published semantic truth, runtime events, or authoritative ledgers; any
resulting claim SHALL pass deterministic checks, ABG admission, and attributed
WM semantic acceptance.

### REQ-ODD-WORLD-MODEL-CONTEXT-MEMORY-CONSTRAINT-004 — No Hidden Context Loss

**Carries**:
- `INTENT.md` — `Constraints`
- `PRODUCT.md` — `Governed Context Memory`

Context selection or compression SHALL NOT hide excluded authority, semantic
loss, unresolved gaps, truncation, or stale inputs behind a completeness claim.
Unknown or unmeasured fidelity SHALL be declared as such.

### REQ-ODD-WORLD-MODEL-CONTEXT-MEMORY-CONSTRAINT-005 — Storage Realization Is Downstream

**Carries**:
- `SPEC_METHOD.md` — `Design Rule`
- `PRODUCT.md` — `Governed Context Memory`

No database, table format, object store, version-control system, vector store,
or prompt-rendering technology SHALL become constitutional context-memory
authority. A realization MAY use those technologies only while preserving the
product's immutable identity, digest, basis, loss, recoverability, and
staleness contracts.

### REQ-ODD-WORLD-MODEL-CONTEXT-MEMORY-CONSTRAINT-006 — No Hidden Context Expansion

**Carries**:
- `INTENT.md` — `Constraints`
- `PRODUCT.md` — `Bounded Mesh Cut`, `Context Basis`

A governed invocation SHALL NOT read undeclared ambient mesh, workspace, chat,
or source state. Expansion beyond the declared bounded mesh cut SHALL produce a
new context basis or an explicit superseding basis with recoverable lineage.
