## Mesh Reprice

Mesh is the current composition form that keeps world-model complexity bounded.
It is not a central model and not a later serving optimization.

The required law is:

```text
local published semantic cuts
  + typed, versioned semantic links
  + recursive reference composition
  -> finite purpose-bound mesh cuts
  -> query, mapping, proof, and application projections
```

This recovers the legacy laws as one system:

- publication gives each local authority one durable unit;
- typed links preserve treatment, covariance, adjoint, composition, and
  supersession meaning across units;
- bounded mesh cuts let an agent or operator load the minimum sufficient
  context for one goal rather than reconstructing a global model;
- edge-specific change propagation limits recomputation and review to the
  affected dependency closure;
- projections can appear in many forms without duplicating semantic truth.

## Gaps In The Existing Mesh Surface

Requirement families 80 and 90 already preserve federation, published-node
participation, references, versioning, common-model reuse, and downstream query
or mapping. They do not yet define:

- mesh as a current complexity-management obligation;
- a first-class typed semantic link with source, target, relation, authority,
  version, treatment/loss, and supersession context;
- a finite purpose-bound mesh cut rooted in exact published refs;
- local dependency-closure impact when a node or link is superseded;
- typed gaps for unresolved refs, incompatible cuts, authority conflict, or
  unreconciled semantic loss;
- the rule that common model is an explicitly adopted role, never ambient
  global doctrine.

Those are requirement gaps. Storage topology such as one manifest versus a
root-plus-records layout remains design.
