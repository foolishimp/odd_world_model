# Decision: Pause T-026 Pending Stable ABIogenesis 5.0

**Date**: 2026-07-12
**Authority**: F_H
**Change class**: goal reprice with downstream design execution pause
**Ticket**: T-026

## Decision

Pause T-026 and move it from the active lane to backlog until an immutable
stable ABIogenesis 5.0 product is released.

The current rc.3 reference kernel remains exact predecessor evidence. It is not
native-carrier closure and shall not be extended into a WM-owned runtime.

## Reason

ABIogenesis 5.0 is the lawful owner of the generic capabilities T-026 needs:

- typed GraphFunction payload execution and higher-order relations;
- the complete declared C runtime, recursion, batching, and retry;
- governed F_P capability selection and result admission;
- ABG events, payload ledger, continuation, replay, and projection;
- public catalog invocation, SDK/CLI contracts, and source-independent install;
  and
- the generic downstream catalog boundary consumed by GLC products.

Rebuilding those mechanisms in WM would create rival runtime authority and
repeat the category error already recorded by the rc.3 as-built review.

## Resume Contract

Stable ABIogenesis 5.0 publication is the trigger for a new dependency intake.
Resume requires:

1. exact package, release, manifest, contract, and digest identities;
2. a WM capability probe over native payload execution, F_P admission,
   recursion/foldback, replay projection, catalog invocation, and install;
3. an exact released GLC product satisfying the downstream-program contract;
4. no product-local shim, runner, ledger, retry loop, or copied substrate law;
   and
5. a recorded T-026 design disposition before implementation resumes.

Release availability without those checks does not admit the dependency.
